# 過去問の取り込み

引数：年度と問番号（例：`/import-past r06a q1`）。省略時は `refs/` の中身を一覧して選んでもらう。

## 手順

1. `refs/` から該当する問題冊子・公式解答例・採点講評（あれば）を探して読む
   - PDF は該当ページだけを読む。見つからなければ、どのファイルを置けばよいか伝えて終わる
2. `questions/past-<年度>-<問番号>.md` を作る
   - `templates/question.md` の形で書く。front matter は `source: past`、`verified: true`、`tags` は `exam/profile.md` のタグから主タグを先頭に選ぶ、`time_limit_min` は profile の目安時間、`issued_at` は取り込んだ時刻
   - 本文・設問は学習者のローカル作業用として取り込む。図はテキストで表現し、表現しきれない図は「refs/<ファイル> の p.<ページ> 図1 を参照」と書く
3. `rubrics/past-<年度>-<問番号>.md` を作る
   - 解答例は公式解答例を用いる。公式に配点がなければ設問の重さから推定し、「推定配点」と明記する
   - 採点講評があれば、出題趣旨と受験者の誤りの傾向を「減点・0点」欄に反映する
   - 必須要素は公式解答例を要素に分解して作る
4. 取り込みが終わったら「`/question past-<年度>-<問番号>` で解き始められます」と伝える

## 注意

- `past-*` のファイルは公式資料の転記を含むため、コミットしない。`.gitignore` に `**/past-*` があることを確認し、なければ追記する
