# 振り返り

## 手順

1. `python3 scripts/stats.py` を実行して、分野別の平均点・回数・推移、ミスの種類の内訳を得る
2. 記録が3件未満なら「まだ傾向を出すには少ない」と伝え、`/question` を勧めて終わる
3. `log/history.jsonl` の `weak` を読み、繰り返し出てくる弱点（同じ用語・同じ観点）をまとめる
4. 次の形で短く返す：
   - **分野別**：平均点の低い順に3つ。合格基準との差も
   - **ミスの傾向**：knowledge / reading / writing のどれが多いか。それぞれの対策を1行ずつ
     - knowledge が多い → 該当用語を参考書で確認し、関連する選択式の過去問を解く
     - reading が多い → 解く前に設問を先に読み、本文に線を引くつもりで根拠を探す練習
     - writing が多い → 解答例と自分の解答の「要素の数」を比べる。字数の8割以上を埋める
   - **繰り返す弱点**：用語や観点を最大5つ
   - **次の3問**：推奨タグを3つ（`scripts/stats.py --next 3`）
5. 学習者が望めば、この内容を `log/review-<YYYYMMDD>.md` に保存する
